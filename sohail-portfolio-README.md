## 🛠️ Local Setup

This is a static site — no build step required.

### 1. Clone the repo
```bash
git clone https://github.com/Sohail123-spec/sohail-portfolio.git
cd sohail-portfolio
```

### 2. Open it
Just open `index.html` directly in your browser, or serve it locally:
```bash
npx serve .
```
